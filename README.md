# AEC Python Automation Basics

![Status](https://img.shields.io/badge/status-learning--in--progress-blue) ![Python](https://img.shields.io/badge/python-3.x-3776AB)

Personal repo where I'm documenting my first steps with Python, engineering math, and basic automation for AEC (Architecture, Engineering & Construction) — starting completely from zero.

## About

I'm a first-year Civil Engineering student. This repo is where I'll track the process of learning to code alongside my degree, with the long-term goal of moving toward **Computational BIM / AEC Developer** work — combining structural engineering knowledge with software instead of relying only on manual drafting and calculations.

Right now that mostly means getting comfortable with Python, the command line, and Git, and slowly connecting what I learn to actual engineering problems.

## Roadmap

- [x] Set up VS Code, Git, and this repo
- [ ] Python fundamentals — syntax, data types, control flow, functions
- [ ] AutoCAD basics — 2D drafting, layer discipline, layouts
- [ ] Small engineering scripts (2D/3D distance, area, geometry) using `math`
- [ ] Intro to OOP, applied to engineering objects (cross-sections, rebar weight)
- [ ] Revit basics & BIM data structure (planned for later this year)
- [ ] Exporting Revit schedules and reading them with `pandas`

This is more of a compass than a fixed schedule — I'll check items off as I actually get to them, not before.

## How I'll document scripts

Once a script is added, I'll keep the write-up short and honest:

1. **Problem** — what it's actually solving
2. **Approach** — the logic or math behind it
3. **Sample output** — proof it runs, not just that it exists
